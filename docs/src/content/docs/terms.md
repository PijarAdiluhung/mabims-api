## Penerimaan

Dengan mengakses atau menggunakan API MABIMS (`api.mabims.dev`), Anda menyetujui ketentuan ini. Jika tidak setuju, jangan gunakan API ini.

## Lisensi

Kode sumber API ini dilisensikan di bawah [MIT License](https://github.com/PijarAdiluhung/mabims-api/blob/main/LICENSE). Data kalender bersumber dari data publik Kementerian Agama RI.

## Tanpa Jaminan

API ini disediakan **"sebagaimana adanya"** tanpa jaminan apa pun, baik tersurat maupun tersirat, termasuk namun tidak terbatas pada jaminan ketersediaan, akurasi, atau kesesuaian untuk tujuan tertentu.

Kami tidak menjamin bahwa:
- API akan selalu tersedia tanpa gangguan
- Data yang dihasilkan selalu akurat atau lengkap
- Hasil komputasi (`mabims-computed`) sesuai dengan pengumuman resmi

## Batasan Tanggung Jawab

Sejauh diizinkan oleh hukum yang berlaku, PIXO Studio dan kontributor tidak bertanggung jawab atas kerugian apa pun yang timbul dari penggunaan atau ketidakmampuan menggunakan API ini, termasuk namun tidak terbatas pada kerugian tidak langsung, insidental, khusus, atau konsekuensial.

**Penting untuk keputusan keagamaan:** API ini bukan sumber otoritas agama. Untuk kepastian hukum syar'i (awal puasa, Idulfitri, Idul Adha), tetap rujuk pengumuman resmi Kementerian Agama RI.

## Penggunaan yang Diizinkan

- Penggunaan pribadi dan komersial tanpa biaya
- Integrasi ke aplikasi, situs web, dan layanan
- Modifikasi dan distribusi sesuai lisensi

## Penggunaan yang Dilarang

- Memutar balik (reverse engineering) atau mengeksploitasi API untuk aktivitas berbahaya
- Melewati batas rate secara sengaja atau sistematis
- Menjual ulang data API sebagai produk mandiri tanpa kontribusi ke proyek

## Perubahan Ketentuan

Ketentuan ini dapat berubah sewaktu-waktu. Penggunaan berkelanjutan setelah perubahan berarti penerimaan ketentuan baru. Perubahan akan dipublikasikan di repository GitHub.
