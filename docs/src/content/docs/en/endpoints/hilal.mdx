Two endpoints for **hilal visibility**: the deciding evening is always the **29th** of the
current month — the night people actually go looking for the crescent. If the criteria are
not fulfilled at any observation point, the month completes 30 days and the start shifts a
day. Month boundaries come from the
**data publik yang dikeluarkan resmi oleh Kementerian Agama RI** (publicly available official MABIMS tables) (not Umm al-Qura), and the astronomy uses a **multi-site model**: the
criteria are evaluated at **coastal observation points across Indonesia** (currently 25
sites, from Sabang to Rote — see [`api/data/hilal_sites.json`](https://github.com/PijarAdiluhung/mabims-api/blob/main/api/data/hilal_sites.json)).

```
GET /api/v1/hilal/info?month={month}&year={year}   → JSON
GET /api/v1/hilal/viz?month={month}&year={year}    → PNG 720×1280
```

`info` carries the numbers + verdict; `viz` renders a "where to look" sky chart with the
same criteria table. Both are public but tightly rate limited
(`info` 60/hour, `viz` 30/hour per IP).

## Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `month` | int 1–12 | yes | **Target** Hijri month (the chart shows its deciding evening) |
| `year` | int | yes | Target Hijri year |
| `retro` | `true` / `false` | no (default `false`) | Unlocks computed retro dates below the curated table (down to 1945-01-01), tagged `mabims-retro`. [See data coverage for the reason why](/en/data-coverage/) |

Model: **"seen anywhere in Indonesia"** — the same Neo MABIMS criteria as the computed
table, evaluated at each point's own local sunset. When the criteria are met, the response
reports the **deciding site** via `deciding_site`.

## Visibility criteria

`visible` is `true` when the criteria are met at **at least one observation point**:

- **Moon altitude ≥ 3.0°** — *topocentric* (the hilal's position relative to the observer),
  with atmospheric refraction applied (Bennett formula);
- **Elongation ≥ 6.4°** — *geocentric* (the Indonesian hisab convention), the moon–sun
  angular separation;

both evaluated at that site's **local sunset** on day 29. The further west a point sits, the
higher the hilal stands at its sunset — so comfortable months are usually decided on the
western coast (Aceh), while months with a southerly lunar declination can be decided along
the southern arc (Java → Lesser Sunda). When the criteria are met nowhere, `deciding_site`
is `null` and the altitude/elongation values come from the best-margin site (closest to
fulfilment).

Sunset/moonset times, azimuths, illumination and lunar age are computed **topocentrically at
the deciding site** (not Sabang), and times are displayed in the site's own timezone
(WIB/WITA).

## Chart (`/hilal/viz`)

A 720×1280 vertical PNG: sunset sky with the crescent (bright limb facing the sun), a
verdict pill (`MEMENUHI KRITERIA` / `TIDAK MEMENUHI` / `MENDEKATI BATAS` / `DI BAWAH HORIZON`) and a
`PARAMETER · MABIMS MIN · STATUS` criteria table plus a **TITIK PENGAMAT** row — the sky scene,
criteria values and times all refer to the same deciding site. Output is deterministic per
parameter.

## Caching

- `Cache-Control: public, max-age=86400, s-maxage=86400` — deterministic per parameter,
  publicly CDN-cached (CDN gets one render per edge location per day).
- Rendering is CPU work: request only what you need and respect the rate limits.

## Errors

| Code | HTTP | Cause |
|---|---|---|
| `out_of_coverage` | 400 | Month/year outside table coverage (see `/meta`) |
| `computation_unavailable` | 503 | Astronomy computation failed |
| `render_failed` | 500 | PNG rendering failed |
| `invalid_retro` | 400 | `retro` param is not `true` or `false` |
