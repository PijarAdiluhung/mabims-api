## Mengapa MABIMS?

API Hijriah umum (berbasis Umm al-Qura) bisa berbeda hingga ±1 hari dari tanggal yang
diamati secara lokal di sekitar batas bulan. Ketika aplikasi Anda menampilkan jadwal sholat
atau acara Islam untuk pengguna Asia Tenggara, satu hari tersebut sangat berarti. API ini
menggunakan tabel yang digunakan oleh otoritas agama regional — dan menandai dengan jelas
setiap data fallback beserta sumbernya.
