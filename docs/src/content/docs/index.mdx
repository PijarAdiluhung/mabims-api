## Mengapa MABIMS?

Hampir semua API Hijriah yang tersedia saat ini, mayoritas berbasis metode Umm al-Qura.
Hasilnya? Tanggal di website/aplikasi Anda bisa berbeda hingga ±1 hari dari tanggal resmi
yang dipakai oleh Kemenag Indonesia. Ketika aplikasi Anda menampilkan jadwal sholat
atau acara Islam untuk pengguna, satu hari tersebut sangat berdampak. API ini
menggunakan kalender resmi yang digunakan oleh Kemenag, disertai dengan fallback ke Umm al-Qura
di luar cakupan pengumuman resmi.
