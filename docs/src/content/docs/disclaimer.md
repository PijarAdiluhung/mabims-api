## Bukan Produk Resmi

MABIMS API adalah proyek independen dan **bukan produk resmi, tidak disponsori, tidak didukung, dan tidak diotorisasi oleh** Kementerian Agama Republik Indonesia atau MABIMS.

## Bukan Data Resmi

Data yang disajikan bersumber dari publikasi Kemenag yang tersedia secara publik. Hasil komputasi (`mabims-computed`) adalah **estimasi algoritmik** berdasarkan kriteria Neo MABIMS dan **bukan pengamatan resmi atau pengumuman pemerintah**.

## Bukan Otoritas Agama

API ini ditujukan untuk **penggunaan teknis dan pengembangan**. Untuk keputusan keagamaan (awal puasa, Idulfitri, Idul Adha), tetap rujuk pengumuman resmi Kementerian Agama RI yang ditetapkan melalui sidang isbat.

## Akurasi

Data disediakan dengan itikad baik namun **tidak dijamin keakuratannya**. Dapat mengandung kesalahan atau keterlambatan pembaruan. Selalu verifikasi dengan sumber resmi untuk keputusan penting.
