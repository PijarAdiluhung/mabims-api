Mengembalikan tanggal **hari penting Islam** dalam satu tahun.

Untuk tanggal yang tersedia di tabel MABIMS, API menggunakan data publik dari Kementerian Agama. Data ini sama dengan yang digunakan oleh endpoint `/convert`.

Untuk tanggal di luar tabel, API menghitung tanggal berdasarkan kriteria Neo MABIMS ([lihat kriterianya](https://mui.or.id/baca/berita/mengenal-kriteria-hilal-mabims-standard-penentuan-awal-bulan-hijriyah-pemerintah-indonesia)). Perhitungan ini memakai ketinggian hilal minimal 3° dan elongasi minimal 6,4° saat matahari terbenam di lokasi pengamatan pesisir di Indonesia.

Dengan begitu, Anda dapat memperoleh perkiraan tanggal hari penting Islam untuk tahun-tahun mendatang.

## Parameter

| Parameter | Tipe | Wajib | Deskripsi |
|---|---|---|---|
| `year` | integer | ya | Tahun pada kalender yang dipilih (`1446` untuk Hijriah atau `2025` untuk Masehi) |
| `calendar` | string | tidak (bawaan `hijri`) | Pilih `gregorian` atau `hijri` |
| `retro` | `true` / `false` | tidak (bawaan `false`) | Mengaktifkan tanggal hasil perhitungan untuk tahun sebelum tabel tersedia, sampai 1 Januari 1945. Data ini diberi tanda `mabims-retro`. [Lihat cakupan data](/data-coverage/) |

    ```php
    foreach ($data['events'] as $event) {
        echo $event['name'] . ' ' . $event['gregorian'] . PHP_EOL;
    }
    ```

```json
    { "event": "awal_ramadan", "name": "Awal Ramadan",             "hijri": "1446-09-01", "gregorian": "2025-03-01", "source": "mabims" },
    { "event": "idul_fitri",   "name": "Idul Fitri",               "hijri": "1446-10-01", "gregorian": "2025-03-31", "source": "mabims" },
    { "event": "idul_adha",    "name": "Idul Adha",                "hijri": "1446-12-10", "gregorian": "2025-06-06", "source": "mabims" }

```

Item diurutkan berdasarkan tanggal Masehi.

## Hari yang tersedia

| `event` | Nama | Bulan Hijriah | Tanggal |
|---|---|---|---|
| `1_muharram` | Tahun Baru Islam | 1 (Muharam) | 1 |
| `maulid_nabi` | Maulid Nabi Muhammad | 3 (Rabiulawal) | 12 |
| `awal_ramadan` | Awal Ramadan | 9 (Ramadan) | 1 |
| `idul_fitri` | Idulfitri | 10 (Syawal) | 1 |
| `idul_adha` | Idul Adha | 12 (Zulhijah) | 10 |

## Catatan

- Jika tanggal berasal dari tabel, nilai `source` adalah `mabims`.
- Jika tanggal dihitung di luar tabel, nilai `source` adalah `mabims-computed`.
- Jika API memakai hasil perhitungan, penjelasannya dicantumkan dalam `warnings[]`.
- Saat memakai `calendar=gregorian`, API mencari tahun Hijriah yang beririsan dengan tahun Masehi yang diminta, lalu mengembalikan setiap hari penting yang termasuk di dalamnya.
- Seperti `/convert`, hasil yang berasal dari tabel disimpan di CDN dan tidak berubah.

## Kesalahan

```json
{
  "error": {
    "code": "invalid_year",
    "message": "..."
  }
}
```

| `code` | HTTP | Penyebab |
|---|---|---|
| `invalid_calendar` | 400 | Nilai `calendar` bukan `gregorian` atau `hijri` |
| `invalid_year` | 400 | Tahun di luar batas yang didukung |
| `invalid_retro` | 400 | Parameter `retro` bukan nilai boolean (menerima `true`/`false`, `1`/`0`) |

Flag boolean menerima `true`/`false` (tidak peka huruf besar/kecil) dan `1`/`0`; tanpa param = false.
