## GET /convert

Mengubah satu tanggal dari satu kalender ke kalender lain. Arah perubahan ditentukan oleh `calendar`.

<ApiRequest path="/api/v1/convert" args="?date={YYYY-MM-DD}&calendar={gregorian|hijri}&retro={true|false}">
  <TestButton path="/api/v1/convert" />
</ApiRequest>

### Parameter

| Parameter | Tipe | Wajib | Deskripsi |
|---|---|---|---|
| `date` | string | ya | Tanggal ISO (`YYYY-MM-DD`) |
| `calendar` | string | tidak (bawaan `gregorian`) | Kalender tanggal masukan |
| `retro` | `true` / `false` | tidak (bawaan `false`) | Mengaktifkan tanggal hasil perhitungan untuk tahun sebelum tabel tersedia, sampai 1 Januari 1945. Data ini diberi tanda `mabims-retro`. [Lihat cakupan data](/data-coverage/) |

### Contoh

<Tabs syncKey="code">
  <TabItem label="curl">
    ```bash
    curl "https://api.mabims.dev/api/v1/convert?date=2025-01-03&calendar=gregorian"
    ```
  </TabItem>
  <TabItem label="JavaScript">
    ```js
    const res = await fetch("https://api.mabims.dev/api/v1/convert?date=2025-01-03&calendar=gregorian");
    const data = await res.json();
    console.log(data.output.date); // "1446-07-03"
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    $response = GuzzleHttp\request('GET', 'https://api.mabims.dev/api/v1/convert?date=2025-01-03&calendar=gregorian');
    $data = json_decode($response->getBody(), true);
    echo $data['output']['date']; // "1446-07-03"
    ```
  </TabItem>
</Tabs>

### Respons

**200 OK**

```json
{
  "input": { "date": "2025-01-03", "calendar": "gregorian" },
  "output": { "date": "1446-07-03", "calendar": "hijri", "day": 3, "month": 7, "month_name": "Rajab", "year": 1446 },
  "source": "mabims",
  "warnings": []
}
```

**400** — format tanggal tidak valid atau kalender tidak dikenal

```json
{
  "error": {
    "code": "invalid_date",
    "message": "'bukan-tanggal' is not a valid ISO date (YYYY-MM-DD)."
  }
}
```

| `code` | Penyebab |
|---|---|
| `invalid_date` | Format tanggal bukan `YYYY-MM-DD` |
| `invalid_calendar` | Parameter `calendar` bukan `gregorian` atau `hijri` |
| `missing_parameter` | Query parameter `date` tidak ada |
| `out_of_coverage` | Tanggal di luar cakupan tabel; lihat [/meta](/endpoints/meta) |
| `invalid_retro` | Parameter `retro` bukan `true` atau `false` |

**404** — `date_not_found`: tidak ada pasangan untuk tanggal tersebut

```json
{
  "error": {
    "code": "date_not_found",
    "message": "No calendar pair exists for 2023-01-01 (gregorian). See /api/v1/meta for coverage."
  }
}
```

:::note
`/convert` tidak bergantung pada zona waktu. Hanya [`/today`](/endpoints/today) yang menerima parameter `tz`, karena tanggal "hari ini" bergantung pada lokasi Anda.
:::

## GET /range

Mengubah setiap hari dalam rentang yang diminta.

<ApiRequest path="/api/v1/range" args="?start={YYYY-MM-DD}&end={YYYY-MM-DD}&calendar={gregorian|hijri}&retro={true|false}">
  <TestButton path="/api/v1/range" />
</ApiRequest>

### Parameter

| Parameter | Tipe | Wajib | Deskripsi |
|---|---|---|---|
| `start` / `end` | string | ya | Tanggal ISO; `start ≤ end`; rentang maks 45 hari |
| `calendar` | string | tidak (bawaan `gregorian`) | Kalender tanggal awal dan akhir |
| `retro` | `true` / `false` | tidak (bawaan `false`) | Mengaktifkan tanggal hasil perhitungan untuk tahun sebelum tabel tersedia, sampai 1 Januari 1945. Data ini diberi tanda `mabims-retro`. [Lihat cakupan data](/data-coverage/) |

### Contoh

<Tabs syncKey="code">
  <TabItem label="curl">
    ```bash
    curl "https://api.mabims.dev/api/v1/range?start=2025-01-01&end=2025-01-03&calendar=gregorian"
    ```
  </TabItem>
  <TabItem label="JavaScript">
    ```js
    const res = await fetch("https://api.mabims.dev/api/v1/range?start=2025-01-01&end=2025-01-03&calendar=gregorian");
    const data = await res.json();
    data.items.forEach(i => console.log(i.gregorian, "→", i.hijri));
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    $response = GuzzleHttp\request('GET', 'https://api.mabims.dev/api/v1/range?start=2025-01-01&end=2025-01-03&calendar=gregorian');
    $data = json_decode($response->getBody(), true);
    foreach ($data['items'] as $item) {
        echo $item['gregorian'] . ' → ' . $item['hijri'] . PHP_EOL;
    }
    ```
  </TabItem>
</Tabs>

```json
{
  "input": { "start": "2025-01-01", "end": "2025-01-03", "calendar": "gregorian" },
  "count": 3,
  "items": [
    { "gregorian": "2025-01-01", "hijri": "1446-07-01", "source": "mabims" },
    { "gregorian": "2025-01-02", "hijri": "1446-07-02", "source": "mabims" },
    { "gregorian": "2025-01-03", "hijri": "1446-07-03", "source": "mabims" }
  ],
  "warnings": []
}
```

Setiap item memiliki `source` sendiri. Rentang yang melewati batas data MABIMS dapat berisi gabungan data publik dan hasil perhitungan.

Untuk `calendar=hijri`, rentang dapat melampaui cakupan tabel publik. Bulan Hijriah di luar tabel dihitung dengan kriteria Neo MABIMS hingga tahun 2100. Batas `start`/`end` tetap 45 hari.

### Penyimpanan di cache

Hasil untuk setiap masukan tidak berubah dan dikirim dengan `Cache-Control: max-age=86400`. Hasil ini aman disimpan di cache mana pun selama satu hari penuh.

### Kesalahan

Semua kesalahan mengembalikan JSON dengan format standar:

```json
{
  "error": {
    "code": "range_too_large",
    "message": "Range is limited to 45 days."
  }
}
```

| `code` | HTTP | Penyebab |
|---|---|---|
| `invalid_step` | 400 | Step bukan `day` |
| `range_too_large` | 400 | Rentang > 45 hari |
| `out_of_coverage` | 400 | Tanggal di luar cakupan tabel |
| `invalid_retro` | 400 | Parameter `retro` bukan `true` atau `false` |
