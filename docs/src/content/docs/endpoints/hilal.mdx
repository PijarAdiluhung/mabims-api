Ada dua endpoint untuk **visibilitas hilal**, dan malam penentuan selalu **malam tanggal 29**, malam rukyatul hilal. Bila kriteria tidak terpenuhi di titik pengamatan manapun, bulan
lengkap 30 hari dan awal bulan bergeser sehari. Batas bulan diambil dari **data publik yang dikeluarkan resmi oleh Kementerian Agama RI**, dan data astronomis dihitung dengan **model multi titik**: kriteria dievaluasi di **titik-titik pengamatan pesisir di seluruh Indonesia** (saat ini 25 titik, dari Sabang sampai Rote — lihat [`api/data/hilal_sites.json`](https://github.com/PijarAdiluhung/mabims-api/blob/main/api/data/hilal_sites.json)).

```
GET /api/v1/hilal/info?month={bulan}&year={tahun}   → JSON
GET /api/v1/hilal/viz?month={bulan}&year={tahun}    → PNG 720×1280
```

`info` berisi angka + verdict (terlihat atau tidak); `viz` merender grafik langit "ke mana melihat". Keduanya publik namun dibatasi rate limit ketat
(`info` 60/jam, `viz` 30/jam per IP).

## Parameter

| Parameter | Tipe | Wajib | Deskripsi |
|---|---|---|---|
| `month` | int 1–12 | ya | Bulan Hijriah **target** (grafik menampilkan malam penentuannya) |
| `year` | int | ya | Tahun Hijriah target |
| `retro` | `true` / `false` | tidak (default `false`) | Buka tanggal retro komputasi di bawah tabel kurasi (s.d. 1945-01-01), ditandai `mabims-retro`. [Lihat cakupan data untuk alasannya](/data-coverage/) |

Model: **"terlihat di mana saja di Indonesia"** — kriteria Neo MABIMS yang sama dengan
perhitungan tabel computed, dievaluasi di setiap titik pada senja lokalnya masing-masing.
Bila kriteria terpenuhi, respons melaporkan **titik penentu** lewat `deciding_site`.

## Kriteria visibilitas

`visible` bernilai `true` bila kriteria terpenuhi di **setidaknya satu titik pengamatan**:

- **Altitud bulan ≥ 3,0°** — *toposentris* (posisi hilal relatif terhadap titik pengamat),
  sudah terkoreksi refraksi atmosfer (formula Bennett);
- **Elongasi ≥ 6,4°** — *geosentris* (konvensi hisab Indonesia), jarak sudut bulan–matahari;

keduanya dievaluasi pada saat **matahari terbenam lokal di titik tersebut** pada hari ke-29.
Semakin barat sebuah titik, semakin tinggi hilal pada senjanya — sehingga bulan-bulan "aman"
umumnya diputuskan di pesisir barat (Aceh), sementara bulan-bulan dengan deklinasi bulan
selatan bisa diputuskan di arc selatan (Jawa → Nusa Tenggara). Saat kriteria tidak terpenuhi
di titik manapun, `deciding_site` bernilai `null` dan nilai altitud/elongasi berasal dari
titik dengan margin terbaik (mendekati terpenuhi).

Waktu matahari/bulan terbenam, azimut, iluminasi, dan umur bulan dihitung **toposentris di
titik penentu** (bukan Sabang), dan waktu ditampilkan dalam zona waktu lokal titik tersebut
(WIB/WITA).

## Grafik (`/hilal/viz`)

PNG vertikal 720×1280 berisi: langit senja dengan bulan sabit (arah cahaya menghadap
matahari), pil verdict (`MEMENUHI KRITERIA` / `TIDAK MEMENUHI` / `MENDEKATI BATAS` / `DI BAWAH HORIZON`), dan tabel
kriteria `PARAMETER · MIN. MABIMS · STATUS` plus baris **TITIK PENGAMAT** — adegan langit,
angka kriteria, dan waktu semuanya merujuk titik penentu yang sama. Output deterministik per parameter.

## Perilaku caching

- `Cache-Control: public, max-age=86400, s-maxage=86400` — hasil deterministik per parameter,
  di-cache publik di CDN (CDN mendapat satu render per edge location per hari).
- Render adalah operasi CPU: gunakan parameter minimal yang Anda butuhkan,
  dan hormati rate limit.

## Error

| Kode | HTTP | Penyebab |
|---|---|---|
| `out_of_coverage` | 400 | Bulan/tahun di luar cakupan tabel (lihat `/meta`) |
| `computation_unavailable` | 503 | Gagal menghitung astronomi |
| `render_failed` | 500 | Gagal merender PNG |
| `invalid_retro` | 400 | Parameter `retro` bukan `true` atau `false` |
